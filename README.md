# チャンネルリマップ（ChannelRemap）
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-blue.svg)](#)
[![Downloads](https://img.shields.io/github/downloads/leftcontroller0518/ChannelRemap/total)](https://github.com/leftcontroller0518/ChannelRemap/releases/latest)

YMM4用の映像エフェクトプラグインです。

映像／画像が持つ色チャンネルを別チャンネルに割り当て、自由に色を変えることができます。

## 主な機能

- RGBモードとHSVモードに対応
- 出力する各チャンネルの参照元を個別に指定
- R・G・B・Aチャンネルの入れ替え
- 輝度（Y）、0、1を使ったチャンネル生成
- GPUシェーダーによるリアルタイム処理

## RGBモード

RGBモードでは、出力R・G・B・Aそれぞれについて、次の値を参照元として選択できます。

- R：元映像の赤チャンネル
- G：元映像の緑チャンネル
- B：元映像の青チャンネル
- A：元映像のアルファチャンネル
- Y：元映像の輝度
- Zero：常に0
- One：常に1

### 使用例

赤と青を入れ替える場合：

```text
出力R = B
出力G = G
出力B = R
出力A = A
```

グレースケール化する場合：

```text
出力R = Y
出力G = Y
出力B = Y
出力A = A
```

アルファチャンネルを赤チャンネルから作る場合：

```text
出力R = R
出力G = G
出力B = B
出力A = R
```

## HSVモード

HSVモードでは、色相（H）・彩度（S）・明度（V）・アルファ（A）を個別に組み替えられます。

- H：色相
- S：彩度
- V：明度
- A：アルファチャンネル
- Zero：常に0
- One：常に1

HSVモードでは、組み替えたH・S・Vの値をRGB映像に変換して出力します。

## 使い方

1. タイムライン上の映像または画像アイテムに「チャンネルリマップ」を追加します。
2. 「モード」でRGBまたはHSVを選択します。
3. 各出力チャンネルの参照元を選択します。
4. プレビューで色の変化を確認します。


## 注意事項

- 初期設定は元映像と同じチャンネル構成です。
- 半透明映像では、アルファチャンネルを考慮して色チャンネルを処理します。
- AviUtl向けの `.exo` 出力には対応していません。
- プラグイン更新時は、YMM4を終了してからDLLを置き換えてください。
